# LearningRecord
日ごとの学習時間を記録する

日ごとの英語学習時間とピアノ練習時間を記録したい。
flaskとpythonで下記の仕様のwebページを作成してください。
ページは1ページだけ。
本日の英語学習時間とピアノ練習時間が表示されている。
日付選択用のドロップダウンリストがあり、日付をさかのぼることができる。初期表示は本日の日付とする。
英語学習開始とピアノ練習開始のボタンがある。
ボタンをクリックすると、「英語学習中」あるいは「ピアノ練習中」と表示され、ボタンは終了ボタンだけになる。
終了ボタンをクリックすると、各学習時間が加算され、もとの英語学習開始とピアノ練習開始のボタンの表示に戻る。
「英語学習中」あるいは「ピアノ練習中」は最大３時間までとし、３時間経過すると自動的に終了ボタンがクリックされた状態になる。
日付をまたいだ場合は、時間を配分して加算する。
時間は日本時間とする。

仕様のポイント解説
3時間制限:
終了ボタンが押された際、またはページを読み込んだ際に「開始時刻から3時間」を超えていないかチェックします。
3時間を超えていた場合は、強制的に「開始から3時間後」を終了時刻として計算し、セッションを閉じます。
日付をまたぐ処理:
例えば、23:30に開始して00:30に終了した場合、前日に30分、当日に30分と分けて加算されます。
whileループを使って、開始日から終了日まで1日ずつ時間を割り振るロジックを組んでいます。
日本時間 (JST):
pytzライブラリを使用して、サーバーのOS設定に関わらず常に日本時間で計算・保存します。
自動リロード:
「学習中」の状態のときは、JavaScriptで1分ごとにページを自動更新するようにしています。これにより、3時間を経過した際に自動的に画面が切り替わります。
実行方法
上記2つのファイルを配置。
python app.py を実行。
ブラウザで http://127.0.0.1:5000 にアクセス。
